# v0.8 Team/DAG Entry-Gate Decision

**Decision: DISABLED**

The v0.7 pilot proved the private runtime pin, signed work-order/receipt boundary, real installed OMO health probe, bounded canary write, cancellation, truthful unavailable behavior and contract-controlled fallback. It did not run a real multi-agent coding workload, did not expose a coordination bottleneck, and did not measure a completion-rate improvement.

Enabling Team/DAG now would add queueing, graph recovery, role handoffs and cost without evidence. v0.8 therefore closes as an explicit no-build decision. The runtime remains at two-worker maximum capability but Team Mode and DAG Mode stay false.

Re-entry requires all of the following measured on a real internal project:

- at least two independent parallel tasks;
- at least one observed coordination blocker;
- at least ten percent completion improvement;
- no false-done regression;
- successful real model execution under the Shipping contract.

The machine-readable decision is `docs/reports/v0.8-entry-gate.json`.
